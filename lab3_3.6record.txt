Step 4: Identify Common Git Errors

1. fatal: not a git repository
Cause: Terminal is outside the Git repository.
Fix: Navigate to the correct project directory.

2. Nothing to commit, working tree clean
Cause: No uncommitted changes.
Fix: Check repository status using git status.

Step 5: Debug API Errors

Test 1: HTTP 404 Not Found

Command:
curl --max-time 15 -i https://jsonplaceholder.typicode.com/posts/9999

Result: HTTP 404
Meaning: Requested resource was not found.
Solution: Check the resource ID and URL.

Test 2: HTTP 401 Unauthorized

Command:
curl --max-time 15 -i https://api.github.com/user

Result: HTTP 401
Message: Requires authentication.
Meaning: Authentication is required.
Solution: Provide a valid GitHub access token.

Test 3: Incorrect API Endpoint

Command:
curl --max-time 15 -i https://jsonplaceholder.typicode.com/post

Result: HTTP 404
Meaning: Incorrect API endpoint.
Solution: Use the correct endpoint /posts.

Step 6: Git Recovery Commands

1. git diff HEAD
Effect: Shows uncommitted changes.

2. git stash
Effect: Temporarily saves local changes.

3. git stash pop
Effect: Restores the most recently stashed changes.

4. git restore <file>
Effect: Discards local changes to a file.

5. git reset --soft HEAD~1
Effect: Removes the latest commit but keeps changes staged.

6. git reset --mixed HEAD~1
Effect: Removes the latest commit but keeps changes unstaged.

7. git reset --hard HEAD~1
Effect: Removes the latest commit and discards changes.

8. git revert <commit-hash>
Effect: Creates a new commit that reverses an older commit.

9. git log --all --oneline --graph
Effect: Displays all branches and commit history.
